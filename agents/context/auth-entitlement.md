# Auth & Entitlement Domain Guide

## 책임

- 사용자 인증 세션을 유지한다.
- 무료 분석 가능 횟수와 구독 상태를 조회한다.
- 분석 요청과 문서 저장의 권한을 서버에서 검증한다.

## 소유 데이터

- `userId`
- 인증 세션과 만료 정보
- `freeAnalysisRemaining`
- `subscriptionStatus`
- 저장 가능 여부와 분석 가능 여부

## 불변 조건

- 앱에 표시된 횟수는 안내용 캐시이며 최종 판정은 NestJS API가 수행한다.
- 무료 횟수 차감은 분석 작업이 서버에 유효하게 접수된 시점의 정책을 따른다.
- 동일 요청 재전송으로 횟수가 중복 차감되지 않도록 요청 식별자를 사용한다.
- 구독하지 않은 사용자가 보관 기능을 우회할 수 없어야 한다.
- 토큰과 사용자 식별 정보를 로그에 평문으로 남기지 않는다.

## 금지 사항

- 클라이언트 로컬 값만 변경해 유료 기능을 허용하지 않는다.
- UI 컴포넌트에서 직접 구독 정책을 계산하지 않는다.
- 인증 실패를 일반 네트워크 오류로 숨기지 않는다.

## 검증

- 로그아웃 상태에서 보호 API가 거부된다.
- 무료 횟수 0일 때 분석 요청이 서버에서 거부된다.
- 미구독 사용자는 분석 직후 결과 확인은 가능하되 장기 저장 정책에 따라 제한된다.
- 중복 요청 시 무료 횟수가 한 번만 반영된다.
