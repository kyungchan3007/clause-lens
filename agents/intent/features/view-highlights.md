# Feature Guide: 분석 결과·하이라이트 보기

## 사용자 목표

위험 가능성이 있는 조항을 목록으로 확인하고 원본 이미지에서 정확한 위치를 찾는다.

## 관련 도메인

- Clause Result
- Highlight Rendering

## 구현 흐름

1. 앱이 최신 page revision의 Clause Result를 조회한다.
2. 이미지 원본 크기와 실제 표시 영역을 계산한다.
3. 원본 boxes를 Skia 좌표로 변환한다.
4. 위험도별 색상과 투명도로 하이라이트한다.
5. 목록의 조항을 선택하면 해당 위치로 이동하거나 강조한다.
6. 법률 자문이 아니라 참고 정보라는 고지를 표시한다.

## UI 규칙

- 색상만으로 위험도를 전달하지 않고 텍스트 또는 아이콘을 함께 사용한다.
- 하이라이트가 원문을 완전히 가리지 않도록 투명도를 적용한다.
- 결과가 없으면 오류가 아닌 `발견된 위험 조항 없음` 상태로 표시한다.
- OCR 신뢰도가 낮은 항목은 확정 표현을 피한다.

## Acceptance Checklist

- [ ] 다양한 화면 크기에서 좌표가 같은 문장을 가리킨다.
- [ ] 이미지 contain 여백과 확대·축소가 반영된다.
- [ ] 조항 선택과 이미지 하이라이트가 연동된다.
- [ ] 색상과 투명도를 토큰으로 변경할 수 있다.
- [ ] 빈 결과와 조회 실패가 구분된다.
