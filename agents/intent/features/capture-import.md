# Feature Guide: 사진 촬영·불러오기

## 사용자 목표

사용자가 계약서를 촬영하거나 갤러리에서 선택해 분석할 페이지 목록을 구성한다.

## 관련 도메인

- Document & Page
- Upload & Storage

## 구현 흐름

1. 카메라 또는 갤러리 권한을 요청한다.
2. 이미지를 촬영하거나 선택한다.
3. 지원 형식과 크기, 디코딩 가능 여부를 확인한다.
4. 로컬 Draft Page를 생성한다.
5. 페이지 미리보기와 재촬영·삭제·순서 변경을 제공한다.
6. 사용자가 확정하면 업로드 단계로 전달한다.

## Draft 최소 필드

- 로컬 식별자
- 로컬 URI
- 페이지 순서
- 너비와 높이
- 업로드 상태
- 오류와 재시도 상태

## 실패 처리

- 권한 거부: 설정 이동 또는 갤러리 대체 경로를 안내한다.
- 촬영 취소: 기존 Draft를 변경하지 않는다.
- 손상 이미지: Draft에 추가하지 않고 재선택을 안내한다.
- 메모리 부족: 원본을 UI 상태에 Base64로 장기 보관하지 않는다.

## Acceptance Checklist

- [ ] iOS와 Android에서 촬영 또는 선택이 가능하다.
- [ ] 취소해도 기존 페이지가 유지된다.
- [ ] 여러 페이지의 순서 변경과 삭제가 가능하다.
- [ ] 잘못된 이미지가 분석 단계로 넘어가지 않는다.
- [ ] 서버 저장 전 데이터가 Draft로 분리되어 있다.
