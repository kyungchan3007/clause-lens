# Feature Guide: 저장·보관하기

## 사용자 목표

분석한 계약서와 결과를 계정에 저장하고 나중에 다시 확인한다.

## 정책

- 분석은 사용자당 3회까지 무료로 제공한다.
- 장기 저장과 보관은 구독 권한이 필요한 기능으로 처리한다.
- 최종 권한 판정은 NestJS API가 수행한다.

## 관련 도메인

- Auth & Entitlement
- Document & Page
- Upload & Storage

## 구현 흐름

1. 앱에서 저장을 선택한다.
2. 로그인하지 않았다면 인증 흐름으로 이동한다.
3. 서버가 구독 또는 저장 권한을 검증한다.
4. 권한이 없으면 구독 안내를 반환한다.
5. 권한이 있으면 문서 보관 상태를 갱신한다.
6. 앱은 서버 문서 목록을 다시 조회한다.

## 불변 조건

- 클라이언트의 구독 화면 상태만으로 저장 완료 처리하지 않는다.
- 이미지 업로드 성공과 문서 보관 완료를 구분한다.
- 저장 실패 시 분석 결과를 화면에서 즉시 제거하지 않는다.
- 사용자가 삭제를 요청할 경우 이미지와 파생 결과의 보존 정책을 함께 적용한다.

## Acceptance Checklist

- [ ] 미로그인 상태에서 로그인 안내가 표시된다.
- [ ] 미구독 사용자의 저장 요청이 서버에서 거부된다.
- [ ] 구독 사용자는 앱 재실행 후 저장 문서를 다시 조회할 수 있다.
- [ ] 중복 저장 요청으로 문서가 복제되지 않는다.
- [ ] 저장 실패와 분석 실패가 다른 메시지로 표시된다.
