# 0037 — 담은 페이지 2열 썸네일 그리드 (순서1 후속) — PRD

> **이슈:** #110 · **상태**: in-progress · **유형**: UI/UX (화면 리디자인 + 드래그 엔진 교체) · **갱신**: 2026-10-01

## 1. 문제
순서1(홈)에서 담은 페이지(②)의 **2열 썸네일 그리드를 보류**했다(세로 드래그 리스트 유지, chrome만). 보류 사유: 2열 드래그 재정렬은 `react-native-draggable-flatlist`(단일 열)로 불가 → **드래그 엔진 교체** 필요. 시안(Home-Pages)은 2열 그리드. 착수 전 Codex 적대 설계 토론 → 수렴.

## 2. 목표
- G1. **2열 썸네일 그리드**(`react-native-sortables` Sortable.Grid, 버전 1.10.1 고정). draggable-flatlist 제거.
- G2. **카드**: 페이지 이미지(contain, 3:4) + 페이지 번호 + 우상단 X(삭제). 길게 눌러 드래그(customHandle=이미지 본문). 그립 핸들 없음.
- G3. **"+추가"**: 그리드 마지막 셀 점선 카드, `fixed-order`(드래그 불가). 표시용 `(PageCell|AddCell)` 배열 — DraftPage[]에 가짜 페이지 금지.
- G4. **탭 = 전체화면 미리보기 모달**(확대) → "이 페이지 교체"·"삭제"(사용자 승인). 교체는 id·order 유지·취소=무변경.
- G5. **표시용 썸네일 생성**(expo-image-manipulator): 카드폭×pixelRatio resize → `DraftPage.thumbUri`, 업로드용 `localUri`와 분리. 교체 시 갱신.
- G6. **데이터 정합성**: 드롭은 ID 순서만 받아 현재 store 재배열(집합 불일치=거부). 드래그 중 편집·분석 차단. clear/잠금전환/이탈 시 세션 무효화.
- G7. **접근성**: 각 카드 "한 칸 앞/뒤" accessibilityActions(끝장 비활성·이동 안내), X·추가 44pt(iOS)/48dp(Android) 실제 영역, 삭제 레이블="N페이지 삭제".
- G8. **동작 보존**: 헤더("담은 페이지 N장"·"길게 눌러 순서 변경")·하단 분석 바(quota·"완료 시 1회 차감"·분석하기). 0장=추가만·분석 금지, 1장=재정렬 비활성, 마지막 삭제→빈 상태.

## 3. 목표가 아닌 것 (Non-goals)
- N1. 무제한 대량 페이지 가상화 — 페이지 상한 내 운용(상한에서 메모리 측정). 상한 초과 요구 생기면 라이브러리 재검토.
- N2. 분석 진행·결과·마이페이지·최근목록(각 순서). 다크·구독.
- N3. 미리보기 모달의 핀치 줌/회전 등 고급 뷰어 — 기본 확대만.

## 4. 제약 (Constraints)
- sortables 버전 **고정**(1.10.1). draggable-flatlist는 실기기 검증·소비처 제거 후 제거. 게이트(expo-doctor·단일 네이티브 버전) 통과는 필요조건 → iOS·Android 실기기로 터치충돌·자동스크롤·화면복귀 별도 검증.
- 드롭 결과를 `setPages` 전체 교체로 반영 금지 → ID-only 재배열. 드래그 중 store 편집 차단.
- 서버 개념 없음(DraftPage 순수 로컬). 완료 전 `checks.sh` PASS.
