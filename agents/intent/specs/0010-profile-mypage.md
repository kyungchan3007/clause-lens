## PRD (왜/무엇)

### 1. 문제
현재 인증 후 헤더에 **로그아웃 텍스트만** 덩그러니 있음. 다른 앱처럼 **프로필/마이페이지**로 묶어 내 정보·고객지원(FAQ·1:1)·로그아웃을 한 곳에서 제공해야 함.

### 2. 목표
- G1. 헤더 **프로필 진입점** → 마이페이지 화면.
- G2. **내 정보**(닉네임·제공자) 표시.
- G3. **FAQ**(앱 내 정적 목록, 펼침/접힘).
- G4. **1:1 문의** 메뉴(진입점만, "준비 중").
- G5(#39). **로그아웃을 프로필 화면으로 이동**.

### 3. 비목표 (후속)
- **1:1 문의 실제 접수 방식**(이메일/카카오 채널/앱 내 폼)은 v1 제외 — 메뉴만 "준비 중".
- 회원 탈퇴, 프로필 편집(닉네임 변경), 약관/개인정보 실제 문서, 알림 설정.

### 4. 제약 (Guardrails)
- 토큰·PII 로그 없음. 내 정보는 `authStore.user`/`GET /auth/me` 범위만.
- FSD: 진입점(라우트)은 app 레이어에서 조합, 화면·로직은 `features/profile`.

### Acceptance (#38)
- [ ] 헤더 프로필 아이콘 → `/profile` 이동 (헤더 로그아웃 제거)
- [ ] 마이페이지 렌더: 내 정보(닉네임·제공자) + FAQ + 1:1 메뉴
- [ ] FAQ 펼침/접힘 동작 · 1:1 탭 → "준비 중" 안내
- [ ] **로그아웃**(계정 섹션) → 확인 다이얼로그 → 세션·서버 refresh 폐기 → 로그인 화면 (실측)
- [ ] `checks.sh` PASS · 토큰·PII 로그 없음

## SDD (어떻게)

### 1. 모듈 구조 (FSD)
```
apps/mobile/src/features/profile/
  ui/ProfileScreen.tsx     내 정보 + 메뉴(FAQ·1:1[·로그아웃(#39)])
  ui/FaqSection.tsx        정적 FAQ 아코디언
  model/faq.ts             FAQ 데이터(정적)
  index.ts
apps/mobile/app/
  profile.tsx              라우트(얇게) → ProfileScreen
  index.tsx                헤더에 프로필 진입점(아이콘) 추가
```
- 내 정보 소스: `useAuthStore().user`(로그인 시 저장). 제공자 라벨(KAKAO→"카카오").
- 게이트: 프로필은 인증 상태에서만 접근(비인증이면 `_layout` 게이트가 login으로).

### 2. 진입점 · 로그아웃 (#38)
- `app/index.tsx` 헤더 = **프로필 아이콘**만(로그아웃 텍스트 제거).
- `ProfileScreen` 하단 "계정" 섹션에 **로그아웃**(`useAuthStore().signOut`) + 확인 다이얼로그.

### 3. FAQ (정적)
- `model/faq.ts`에 `{ q, a }[]` 3~5개(무료 횟수·분석 정확도·데이터 보관·로그인 등). 원격화는 후속.
- 아코디언: 항목 탭 → 펼침(로컬 state). 접근성 role 부여.

### 4. 1:1 문의 (준비 중)
- 메뉴 항목 탭 → Alert/토스트 "준비 중입니다". 실제 접수(이메일/채널/폼)는 후속 태스크.

### 5. 검증
- 시뮬레이터 스모크: 헤더 프로필 → 마이페이지 → FAQ 펼침 → 1:1 "준비 중" → (#39) 로그아웃.
- `checks.sh` PASS.

### 6. 후속(이 태스크 밖)
