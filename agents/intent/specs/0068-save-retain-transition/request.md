## 요약
- TASK-006 ② — 분석 결과·사진 "저장하기"로 장기 보관 전환
- 설계: ADR-12

## 설계
- 보관 상태 추가
  - `TEMPORARY` (무료, 완료+7일)
  - `SAVED` (구독 보관)
  - `DELETING` (삭제 예정)
  - `savedAt`
- `retainUntil`(완료+7일)은 유지
  - 유효 기한은 보관 상태로 계산 (먼 미래 날짜 반복 기록 안 함)
- 저장 흐름 (멱등)
  - 결과 확인 → 저장 요청
  - 서버가 소유권·완료·미만료·구독 권한 확인
  - 원자적 상태 전환 → 목록 재조회
- 상세·목록·삭제가 **같은 보관 판정 함수** 공유
- 운영 노출은 기능 플래그로 제한

## 범위 밖
- 결제(④) · 실삭제(③)

- [ ] 결과 화면 저장하기 + 목록 반영
