## 1. 문제
- 홈 리디자인(TASK-U1 #106·#107, TASK-U1b #112) 이후 Maestro 시나리오가 사라진 문구를 기다려 깨짐.
  - 로그인 후 홈 앵커 `계약서를 담아주세요` → 홈에서 제거(촬영 EmptyState 전용, 현재 홈 경로에서 미사용).
  - 홈 "최근 분석" 섹션·`아직 분석한 계약서가 없어요` 빈 안내 → `최근 분석 N건` 진입 버튼 + /recent 목록으로 대체.
  - `촬영하기` → `계약서 촬영` · 페이지 텍스트 `1페이지` → `담은 페이지 N장`(헤더)·`1페이지 삭제`(접근성 라벨).
  - `업로드 완료`·`분석 완료` → ProcessingScreen `계약서를 분석하고 있어요`·`분석이 끝났어요`/`일부만 분석됐어요`.
- 리디자인 태스크에서 시나리오 트리거(문구 변경→yaml 동기화)가 누락됨(#119 중 발견).

## 2. 목표
- G1. 모든 `apps/mobile/.maestro/*.yaml` 단언 문자열을 실제 UI 문자열(`apps/mobile/src`·`app` grep 근거)과 일치.
- G2. 로그인 후 홈 앵커를 Hero `계약서, 찍기만 하세요`(온보딩·최근있음 공통)로 통일.
- G3. `SCENARIOS.md` Given/Then 문구 동기화.
- G4. 시뮬레이터(로그인 상태)에서 자동 가능한 시나리오 실측.

## 3. 목표가 아닌 것 (Non-goals)
- N1. 앱 코드·문구 변경 없음(서버가 진실, UI가 기준 — yaml이 UI를 따라감).
- N2. 수동 구간(카카오 자격증명·OS 사진 피커·권한 다이얼로그) 자동화.
- N3. 백엔드 seeding 자동화.

## 4. 제약
- 카카오 로그인 자동화 불가 → login·login-failure·capture-gate·logout은 상태 파괴/수동 → 실측 범위 명시.
