# 0058 — 과정 기록 (trace)

> 작업하며 실제 판단·막힘·되돌림을 남긴다. 자동 사실 기록은 `.harness/trace/<폴더>.jsonl`(hook, git 미추적), 여기는 사람이 쓰는 판단 기록.

## 판단
- **A+B 병행 채택.** A(위치 이동)로 원인을 없애되, 과거/타 경로 잔재가 이미 로컬에 있을 수 있어 B(게이트 스킵)도 함께 둠. 이슈도 "택1 또는 병행"을 열어 둠.
- **B 기준을 좁게.** "미추적 파일만 있는 폴더"로 잡으면 커밋 전 현재 태스크 폴더까지 건너뛰어 진짜 누락을 놓침. 그래서 `prd·sdd·trace 전무 + trace.auto.jsonl류 미추적만`으로 한정.
- **현재 브랜치 진짜-누락 보장 확인.** 재현 시 잔재 폴더(0099)는 오탐이 사라졌고, 남은 FAIL은 내 태스크(#154)의 spec 부재였음 — 즉 "브랜치 이슈 spec 없음" 검사가 진짜 누락을 따로 잡아 줌을 실측으로 확인.
- **gitignore 과거 패턴 유지.** 새 `.harness/trace/`를 추가하면서도 `specs/**/trace.auto.jsonl` 줄을 남겨 기존 잔재가 실수로 커밋되지 않게 함.

## 막힘 / 되돌림
- 특별한 되돌림 없음. tmp 테스트에서 git 미추적 판정을 재현하려 `git init` + `git add`로 "추적/미추적" 두 경우를 각각 구성(비-git tmp에선 ls-files가 ""라 미추적으로 처리됨).
- 재현용 임시 잔재 폴더(0099-residual-sim)는 검증 후 삭제.
