# 0039 — 구독 예고 UI (무료 소진 403 + 최근 목록 구독 카드) — PRD

> **이슈:** #114 · **상태**: in-progress · **유형**: UI (시안 선반영) · **갱신**: 2026-10-01

## 1. 문제
시안에 있으나 미구현인 **구독 예고 UI** 2곳. 실제 구독 결제는 TASK-006(후속)이고, 지금은 **안내 UI만** 선반영.
- ⑥ 무료 소진(403): 분석 요청 403(무료 횟수 없음) 시 현재는 제네릭 error("현재 사용할 수 있는 무료 분석 횟수가 없어요") — 시안은 전용 화면.
- ⑨ 최근 목록: 하단 구독 안내 카드 + "구독 알아보기 (곧 제공)" 버튼 — 미구현.

## 2. 목표
- G1. **무료 소진 전용 화면(⑥)**: 분석 403이면 전용 화면 — 티켓 아이콘(앰버) + "무료 분석 횟수가 없어요" + "무료 3회를 모두 사용했어요. 진행 중인 분석이 있다면 끝난 뒤 다시 시도해 주세요." + 구독 Notice(별 아이콘, "곧 **구독**으로 무제한 분석을 제공할 예정이에요.") + **확인** + **남은 분석 상태 보기**.
  - 403 식별: analysis error를 **errorKind="quota"**로 표시(제네릭 error와 분기). 다른 error는 기존 ProcessingScreen error 유지.
  - 확인 → 분석 error 닫고 idle 복귀(담은 페이지 유지, 재시도 가능) = 기존 onCancel 재사용.
  - 남은 분석 상태 보기 → /recent.
- G2. **최근 목록 구독 카드(⑨)**: /recent 하단 고정 — 방패 + "분석 결과를 계속 보관하세요" + "무료 결과는 7일 뒤 사라져요. 구독하면 기한 없이 보관하고 언제든 다시 볼 수 있어요." + **"구독 알아보기 (곧 제공)"** 버튼(구독 미구현 → 안내).
- G3. **동작 보존**: 기존 분석 흐름(일반 error·취소·재시도·done/partial)·최근 목록(무한스크롤·당겨 새로고침·행 탭).

## 3. 목표가 아닌 것 (Non-goals)
- N1. 실제 구독 결제·플랜·백엔드(TASK-006). "구독 알아보기"는 안내만(네비게이션 없음 또는 "곧 제공" 안내).
- N2. 마이페이지(⑤)·결과(순서3). 다크.
- N3. 403 원인별 세분(예약 중 vs 소진) — 서버 메시지 기준 단순 안내.

## 4. 제약 (Constraints)
- 서버가 진실: 403을 "모두 사용"으로 단정하는 문구는 서버 정책(무료 3회) 범위에서만. 클라가 횟수 임의 판단 금지.
- 전용 화면은 표시 전용(props만). 완료 전 `checks.sh` PASS.
