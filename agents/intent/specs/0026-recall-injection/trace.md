# 0026 — 과정 기록 (trace)

## 판단
- **JOURNAL 파서 재작성**: harness-lab `recentJournal`은 표(`| 날짜 | 태스크 | ... |`) 기반. ClauseLens JOURNAL은 `## 날짜 · Claude · 제목` 섹션 + `- **무엇**/**다음**` 불릿 → 섹션 헤딩을 스캔해 최근 N개의 날짜·제목·다음할일을 뽑도록 재작성.
- **효과 측정은 후속**: 주입을 켜도 참조율 변화는 1~2주 데이터가 쌓여야 보임. Acceptance의 측정 항목은 "후속"으로 남기고, `pnpm metrics`가 지금도 기준선(현재 33%)을 재출력하는지만 확인.
- **guard 활성 상태 대응**: 이 세션에 #84 훅이 켜져 있어, 코드(agents/harness) 편집 전에 폴더 spec 0026(prd·sdd)을 먼저 만들어 guard가 허용하도록 순서를 잡음.
- **비차단 주입**: recall/session-context는 stdout→컨텍스트라 guard처럼 차단하지 않음. 안전.

## 막힘 / 되돌림
- **검증 결과**: recall-hook에 UserPromptSubmit JSON을 주입하니 실데이터로 미처리 `[보완]`(#83·#84 커밋에서, 이후 언급된 것 제외)·최근 JOURNAL 3개(다음/주의 포함)·작업 상태(브랜치·이슈·폴더 정상)를 주입, 같은 세션 재요청은 빈 출력(반복 억제). `pnpm metrics`는 복기 참조율 35%(기준선 33% 대비 +2%) 출력. 단위 10개 통과.
- **되돌림 없음** — 설계대로 진행. 효과(참조율 변화)는 데이터 축적 후 측정(후속).
