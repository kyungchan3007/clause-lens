## 1. 문제
순서1(홈, #106) 이후 시안과 차이 발견(사용자 지적·시안 재확인).
- 온보딩 Hero 아이콘이 시안(ShieldCheck·네이비)과 다름(현재 ScanLine).
- 홈 '최근있음'이 인라인 카드 목록 — 사용자는 **원할 때 인터랙션으로** 보길 원함.
- DocumentRow 날짜가 "오늘 HH:MM"(시간)·좌측 문서 아이콘 — 시안은 "오늘/어제"·라인 플레이스홀더.

## 2. 목표
- G1. **온보딩 Hero 아이콘**: ScanLine → **ShieldCheck**(네이비, 신뢰 톤). 제목·부제·버튼·3단계·고지는 유지(시안 Main 일치).
- G2. **홈 '최근있음' → 진입 버튼**: 인라인 최근 카드 제거 → **"최근 분석 N건 >" 진입 버튼** → 기존 `/recent` 전체 화면(사용자 결정). 로딩=스피너·에러=다시 시도·0건=온보딩이 처리(렌더 안 함).
- G3. **DocumentRow 보정**: 날짜 "오늘 HH:MM" → **"오늘/어제/M·D"(상대일, 시간 미표시)**; 좌측 문서 아이콘 → **라인 플레이스홀더**(연한 가로 라인, 썸네일 느낌). /recent 전체 목록에 공용 적용.
- G4. **동작 보존**: 촬영·갤러리·홈 4상태(온보딩/최근있음/로딩·실패/페이지 담음)·잔량 칩·재열람 진입·접근성.

## 3. 목표가 아닌 것 (Non-goals)
- N1. 실제 이미지 썸네일(DocumentRow는 라인 플레이스홀더만 — 서버 썸네일은 후속).
- N2. 갤러리 버튼 제거(유지). 결과·마이페이지·최근목록 화면 디자인(순서3~5). 다크.
- N3. 홈 최근 인라인 미리보기 복구(진입 버튼으로 대체).

## 4. 제약 (Constraints)
- 서버 값만 표시(앱이 날짜·건수 임의 가감 없음). `completedAtLabel`은 상대일만.
- DocumentRow는 홈·/recent 공용 — 변경이 양쪽에 반영됨(이번엔 홈 인라인 제거로 주로 /recent에 노출).
- 설계 방향은 사용자 Q&A로 확정(진입 버튼→전체화면). 완료 전 `checks.sh` PASS.
